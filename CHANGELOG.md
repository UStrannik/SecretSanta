# Список изменений (Changelog)

Все заметные изменения в проекте «Тайный Санта» будут фиксироваться в этом файле.

Проект придерживается семантического версионирования (Semantic Versioning).

---

## — 2026-01-25

Это первый стабильный релиз программы.

### Реализован основной функционал
- **Ядро жеребьевки**: Алгоритм случайного распределения пар, гарантирующий, что участник не может выбрать самого себя.
- **Поддержка SMTP**: Реализована отправка писем через протокол SMTP.
- **Предустановки для GMail**: Настроены порты и адреса серверов по умолчанию.
- **Импорт данных**: Возможность загрузки списка участников из файла `list.txt`.
- **Система проверки**: Кнопка «Тестовое письмо» для проверки корректности настроек почтового сервера.
- **Мастер-отчет**: Автоматическая отправка полного списка распределенных пар на почтовый ящик организатора.
