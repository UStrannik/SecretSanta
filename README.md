# 🎅 Тайный Санта (Secret Santa)

**Текущая версия 1.0.1.**
Полный список изменений доступен в CHANGELOG.md

Программа для автоматизации корпоративной игры «Тайный Санта». Забудьте о бумажках в шапке — программа сама распределит участников и разошлет персональные письма каждому «Санте» на электронную почту.

---

### ✨ Основные возможности

- **Автоматическая жеребьевка**: Умный алгоритм перемешивания исключает возможность выпадения самого себя.
- **Импорт участников**: Быстрая загрузка списка имен и email из предварительно подготовленного текстового файла (пример - list.txt).
- **Гибкая настройка SMTP**: Поддержка любых почтовых серверов (по умолчанию преднастроен GMail).
- **Контроль доставки**: Функция «Тестовое письмо» для проверки связи с сервером перед основной рассылкой.
- **Мастер-список**: Отправка итогового списка всех пар на почту организатора для координации финала игры.

---

### 🚀 Технологический стек
- **Язык**: C++
- **Фреймворк**: Qt 6
- **Система сборки**: qmake
- **Компилятор**: MinGW

---

### ⚙️ Установка и сборка

1. **Клонируйте репозиторий**
2. **Откройте проект в Qt Creator** (файл SecretSanta.pro)
3. **Настройте сборку** (комплект с Qt 6 и MinGW)
4. **Соберите и запустите** (Ctrl + R)

**Либо скачайте готовый релиз и запустите SecretSanta.exe**

### 📋 Подготовка списка (list.txt)
Файл должен быть текстовым в кодировке utf-8 и иметь следующую структуру:
```text
Имя Участника <email1@example.com>
Имя Участника <email2@example.com>
Имя Участника <email2@example.com>
```

### 🗺 План развития (Roadmap)
**Управление списком:** Добавить редактор участников (добавление/удаление/правка).

**Экспорт:** Сохранение сформированных пар в файл.

**Стабильность рассылки:** Реализация отправки писем «пачками» через несколько соединений для предотвращения блокировок со стороны SMTP-серверов.

**Кастомизация:** Редактор шаблонов писем (изменение текста и оформления поздравления).
